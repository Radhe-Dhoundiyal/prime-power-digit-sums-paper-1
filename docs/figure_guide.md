# Figure Guide

All four figures use the exact statistic and manuscript notation.

1. `figure1_raw_values_exact.png`: raw \(\widetilde A_p(n)\) for
   \(p=2,3,5,7,11\), \(n=1,\ldots,400\).
2. `figure2_running_mean_exact.png`: \(\widetilde\mu_p(N)\) for the same
   primes, \(N=1,\ldots,2000\).
3. `figure3_prefix_mean_cutoffs_exact.png`: exact prefix means for
   \(p=2,5,11,101,197\) at the seven official cutoffs.
4. `figure4_prefix_std_exact.png`: exact sample prefix standard deviations
   for the same primes and cutoffs.

Figures 1 and 2 intentionally use shorter ranges. Plotting all 8000 values
causes visual compression and reduces interpretability. The complete
experiment remains available in the dataset. No all-50-prime line plot is
generated or published.
